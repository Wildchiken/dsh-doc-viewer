# 详细说明

[English](guide.md) · 简体中文

## 用法

- 侧边栏「文档」与「自动化任务」并列。切到会话再回来，打开的文档、编辑和撤销历史都还在；重启 Harness 后，上次打开的文档会重新打开。
- **Harness 里默认用它打开**：在对话里的文件链接、右侧栏文件树里点 xlsx / xls / csv / tsv / et / wps，直接在右侧栏打开成可编辑的表格；预览顶部的渲染器菜单可以切回 Harness 自带的预览。PDF、Word、Markdown、文本仍默认用 Harness 的预览，菜单里可以选「文档插件」。需要带文档预览接口的 Harness（0.2.2 起）。
- **在对话旁打开**：文档可以作为 Harness 右侧栏的一个标签页，和对话并排（右侧栏「＋」里的「文档」，或文档页顶栏的并排按钮；同一按钮切回整页）。你在对话里时，Agent 打开文档也是开在对话旁，不切走。整页和对话旁是同一个文档页，打开的文档、未保存修改和撤销历史跟着走。需要带右侧栏的 Harness（0.2.2 起）。
- **和 Agent 一起改**：Agent 改文件时不会把你从对话里拽走，只在「文档」入口上加个点。已打开的表格原地更新，视图、选区和撤销历史不变；顶栏的「Agent 改了 N 处」列出每次改动，可以逐处跳过去或整组撤销。你有没保存的修改时，Agent 的改动直接放进你正在编辑的表格，下次 ⌘S 一起写入，不另存副本。 Agent 写过的单元格会用带「Agent」标签的蓝框标出来，一直留到你点进表格或开始输入（最多 1 分钟），读完 Agent 的回答再看也来得及；滚动查看不会让它消失。你不在这页时不计时，不滚动、不抢选区。
- **打开**：「打开…」/ ⌘O 用系统的打开面板，文件在原处打开，不复制。从访达拖进来的文件网页拿不到原路径，只在系统临时文件夹里放一份，保存时会问存到哪。
- **新建表格**：「＋」菜单、空状态的「新建表格」或 ⌘N，在系统保存面板里定名字和位置，建好直接打开。默认名会避开已有文件。
- **保存**：⌘S 直接存回原文件。覆盖前自动把原内容存成一个版本（`~/.dsh/doc-viewer/versions`，每个文件最近的版本加最早的一份、共 20 个，保留 30 天，不占你的文件夹），保存后可以点「撤销保存」并逐步继续撤销，也可以在菜单「恢复到之前的版本…」找回。
- **打开不等重算**：脚本或 Agent 生成的表格常常只有公式、没存结果。打开时先显示表格，内置引擎能算的先算出来；LibreOffice 在后台把全部公式算完再补上（XLOOKUP 这类内置引擎不支持的函数也有结果），不算一次修改。Harness 刚启动时 LibreOffice 要十几秒才能起来，这段时间里表格照样能看能改。
- **没保存就退出**：编辑停下后会把未保存的修改存一份快照（`~/.dsh/doc-viewer/recovery`），下次打开文档页时自动恢复，也可以选择放弃。
- **不会冒险覆盖**：原文件里有本插件写不回去的东西（图表、数据透视表、宏、条件格式、数据验证、批注、图片），是旧版 `.xls/.et`，或打开后被别的程序改过，就不覆盖，说明原因并让你选位置另存。
- **保存 / 另存为… / 导出 PDF…**：三个说法各管一件事——「保存」存回原文件，「另存为…」换位置或格式存一份新的（之后这个标签就是新文件），「导出 PDF…」生成 PDF、原文件不动。另存和导出弹出系统的保存面板，默认在原文件旁边、同名，由你决定放哪。批量转换和 Agent 生成的文件放在各自原文件旁边。
- **问 Agent**：顶栏「问 Agent」会切到对话，并把「关于「文件」，选中的范围：」预填进输入框，补一句话就行；出错提示里也有这个按钮。
- 快捷键：⌘O 打开、⌘N 新建表格、⌘S 保存、⌘F 查找。
- **语言**：界面和 Agent 工具返回的文字跟随 Harness 的语言（设置 → 通用 → 语言），支持中文和英文。
- 系统开了「减弱动态效果」时，界面不做动画。

| 类型 | 能做什么 |
| --- | --- |
| 表格 xlsx / xls / csv / tsv / et | 编辑、公式实时联动重算、跨表引用、合并单元格、筛选、查找替换、文本转数字、分组统计与图表、导出排好版的 PDF |
| PDF | 连续阅读、缩略图、可选中复制的文字、页内高亮查找；合并、拆分、删页、OCR（macOS Vision）、转文本/Word/Excel |
| Word docx / doc / wps | 预览（沙盒隔离）、导出 PDF、提取文字 |
| 文本 / Markdown | 直接编辑并存回原文件，保留原来的编码（UTF-8 / GB18030 / UTF-16）和换行；查找高亮；Markdown 默认显示排好版的预览（可切到编辑），预览和导出的 PDF 用同一个解析器，标题、表格、列表、引用、代码都有格式 |

## 导出的 PDF

表格：A4，列宽按内容自动调整，宽表自动横向、缩放到一页宽，表头加粗浅底并在每页重复，浅色表格线，页脚有文件名和页码。原表自己设置过颜色/边框的保持原样。文本：按正文排版而不是表格单元格。

## Agent 工具

`doc_viewer_create`（新建 xlsx / csv / md / txt，表格可以直接带表头、数据和公式，建好在对话旁打开；不会覆盖已有文件）、`doc_viewer_context`（用户正在看哪个文档、哪个工作表、选中了哪里、第几页）、`doc_viewer_open`（展示给用户）、`doc_viewer_read`、`doc_viewer_edit`、`doc_viewer_stats`、`doc_viewer_convert`、`doc_viewer_pdf`。

- 不传 `path` 时，读、改、统计都作用于用户当前打开的文档，所以用户说“把选中的这列求和”就够了。
- `doc_viewer_edit` 同一个文件的调用排队执行，并行调用也不会互相覆盖；写入前先计算校验，公式语法错误、函数不存在、循环引用自身、写到合并单元格内部时什么都不写，并说明要改什么；其他公式错误（如 `#DIV/0!`）照常写入并提示。返回值列出每个写入单元格的改前改后，以及因此变化的公式结果（含合计）。它按和 ⌘S 相同的规则直接改原文件并留版本，用户在文档页有未保存修改时改动进页面而不是文件；已打开的文档页原地更新、不切换页面，改动记进「Agent 改了 N 处」清单。只有文档页不在线、或改动超出了表格当前范围时，才另存在旁边。
- `doc_viewer_stats` 默认不计入合计行（对上方同一列求 `SUM` / `SUBTOTAL` 的行），免得重复相加，并在结果里说明跳过了哪几行；传 `includeTotals: true` 才计入。
- `doc_viewer_read` 单次返回量按当前模型的 `contextWindow` 换算（运行期经 `llm.resolveModelInfo` 读取），不针对某个模型写死；超出时在行/页/字符边界截断，并告诉模型下一次该传什么参数。

## 已知边界

- 保存 xlsx 时用 LibreOffice 算出每个公式的结果写进文件，所以其他程序不用计算也能读到正确的值；没有 LibreOffice 时，常见公式（四则运算、引用、SUM / AVERAGE / MIN / MAX / COUNT / ROUND / ABS）在本插件里算出；其余公式不写结果，Excel 打开时会重新计算，写入前也没法检查函数名是否存在。Excel 独有、LibreOffice 没有的函数（如 `LAMBDA`）Agent 不能写入。
- 表格自带的引擎没有 `XLOOKUP`、`FILTER`、`LET` 等较新的函数。用到它们的工作簿在编辑后约 1 秒内由 LibreOffice 给出结果，这期间可能短暂显示 `#NAME?`；超过 20 万个单元格时不做实时计算，保存后重新打开才是正确结果。
- 保存表格时打开原文件、只写入改动的单元格（值、公式、字体、填充、对齐、数字格式、边框、合并、行高列宽、冻结），插入/删除的行列先在原文件上重放。超链接、命名区域、隐藏工作表、打印设置、条件格式、数据验证、图片、批注、主题色等原样保留。
- 含图表、数据透视表、宏、切片器、表单控件、迷你图、形状/文本框的文件不会被覆盖，只能另存（另存的副本里没有这些内容）。
- 在表格里排序只移动值，单元格格式留在原位置（和 Excel 不同）；单元格内的富文本在编辑过的单元格上会变成普通文本。
- Markdown 里的图片在预览和 PDF 里都显示为「[图片：说明文字]」，不加载图片文件。
- 原处保存通过软链接时写入链接指向的文件，并保留文件权限；硬链接和 Finder 标签等扩展属性不保留。
- 系统的保存/打开面板：macOS 用系统自带的，Linux 上用 zenity（未实测）；没有面板时，导出放在原文件旁边。
- 深色模式下表格网格通过反色显示，单元格里的颜色会随之变化（文件本身不受影响）。
- PDF 转 Word/Excel/CSV 是尽力还原，复杂排版、图片和分栏会丢失，会先提示确认。
- 旧版 `.doc` / `.wps` / `.et` 依赖 Harness 自带的 LibreOffice Kit。
- OCR 用 macOS 自带的 Vision，需要 macOS 13 或更新版本（Apple 芯片和 Intel 都可以）。
- 超过 2 MB 的文本文件和从访达拖进来的文件只读，不能保存回去；Word 和 PDF 不能编辑。
- 大表打开需要等一会儿：机器较忙时，2 万行要几十秒。
- 只在 macOS 上测过，Linux 和 Windows 没有试过，欢迎反馈。

## 开发

```bash
pnpm install
pnpm build      # 生成 client.js（启动时加载）和 client.viewer.js（首次打开页面时才加载）
pnpm test       # 引擎测试，用真实文件跑；DSH_LIBREOFFICE_CLI=none 时模拟没有 LibreOffice 的环境（CI 就是这样跑的）
pnpm pack       # 打包，prepack 会先构建前端和 OCR 小程序（需要 Xcode 命令行工具）
```

```
index.js                 Host 路由 + 插件注册
src/host/
  documents.js           打开/读取/编辑/统计/转换/PDF 操作，原处保存，带解析缓存
  formula-lite.js        没有 LibreOffice 时计算常见公式
  encoding.js            文本编码识别与按原编码写回
  i18n.js / locale-en.js Host 消息的语言和英文词典
  versions.js            原处保存前的版本备份与恢复
  recovery.js            未保存修改的快照，退出或崩溃后恢复
  native.js              系统打开/存储面板
  print.js               导出 PDF 的排版（表格页面设置、文本转文档）
  xlsx-patch.js          只把改动写回原工作簿；检测写不回去的内容
  spreadsheet.js         ExcelJS/SheetJS 解析与写出、公式归一化
  pdf.js                 PDF.js 文本提取、pdf-lib 页面操作、Word 预览、OCR
  libreoffice.js         复用 officeToPdf，回退 LibreOffice Kit CLI
  tools.js               doc_viewer_* agent 工具
src/client/
  main.jsx               侧边栏入口、主区域页面、常驻挂载、agent 请求轮询
  viewer.jsx             文档页（懒加载）
  SpreadsheetTab.jsx / PdfTab.jsx / DocumentTabs.jsx / Dialogs.jsx
  styles.js              全部使用 Harness 主题变量，跟随明暗主题和皮肤
  i18n.js / locale-en.js 界面语言和英文词典（中文原文就是键）
test/                    引擎测试
```
